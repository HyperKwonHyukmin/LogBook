# LogBook 사용성 검토 (2026-11-23, ego-browser)

145 운영 화면(http://10.14.42.145:9095)을 관리자 계정으로 둘러보기만 함(자료 수정 없음). 2560px 와 1366px 에서 가로 넘침, 잘림 없음. 페이지 이동은 대부분 0.2~0.8초.

## 찾은 것 (중요한 순서)

1. **자료 상세: 3D 미리보기가 파일 트리 아래** — 1366px 에서 스크롤해야 보임. → 2026-11-23 logbook-20 세션이 미리보기를 트리 위로 옮김(EntryPage.jsx, 시험 추가). 남은 점: 트리 아래쪽 파일을 고르면 위쪽 미리보기만 바뀌어 짧은 화면에서는 올려 봐야 함(고를 때 미리보기가 화면 밖이면 그쪽으로 스크롤하는 보완을 추천).
2. **활동 로그: 대상이 번호로만 보임** — `E000254`, 묶음 번호 `20261120-132036-d027`. 무슨 자료인지 눌러 봐야 앎 → 자료 제목을 붙임.
3. **비슷한 모델 찾기: 최근 BDF 목록 상자 높이 약 280px 고정** — 30개 중 6개만 보이고 화면 절반이 빔 → 화면 높이에 맞춤.
4. **호선 화면(/h/3020) '참여자 권혁민 8건'** — 올린 사람을 센 것으로 보임. 같은 자료의 담당자는 김미희 → 담당자 기준으로 세거나 이름을 '올린 사람'으로.
5. **검색 결과: 썸네일 없는 자료가 아이콘 없는 회색 상자** (M21 ttt2, M22 goliat 등) → '썸네일 없음' 표시.
6. **관계 지도 주황 안내 "내용 서명이 없는 BDF 239개는 모델 관계에서 빠졌습니다"** — 일반 사용자가 뜻과 할 일을 모름 → 쉬운 말로, 또는 관리자에게만.

## 작은 것
- 검색 안내 "검색어의 3020 는" 조사 어색함("3020은").
- 호선 화면 목록 `선미부 · Rudder · 6` 만 제목 앞 호선 번호 없음(자료 제목 문제).
- `E000177` 에 같은 PDF 가 `fe_model` 과 `report` 에 두 번(자료 정리 문제).
- 검색 화면에 12px 미만 글자 13곳(결과 요약 줄 등).

## 재현 못 한 것
- 처음 한 번 활동 로그, 문서 본문 화면이 2~4초 동안 메뉴까지 통째로 빈 화면. 다시 열면 0.3초 안에 뜸. 서버가 처음 깨어나서였을 수 있으나 원인 미확인.

## 보지 않은 것
- 실제 올리기와 확정, 관리 화면, 휴대폰 화면(운영 자료를 바꿀 수 있거나 범위 밖).
