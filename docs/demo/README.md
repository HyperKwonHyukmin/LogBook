## 발표 순서(제안)

1. **지금** — 실제 LogBook `/graph`: 자료 18건이 호선별로 모인 모습. "자료를 확정하는 것만으로 지도가 생긴다."
2. **쌓이면** — 이 시안 파일로 전환: 같은 화면에 자료 64건.
   - 호선 사이 **굵은 곡선**에 마우스 → "3496 ↔ 3542 · 관계 9건 · 함께 등록 4 · 형상이 같은 BDF 4쌍 …" 설명이 뜬다.
   - 호선 점에 마우스 → 주변이 가라앉고 연결이 바깥으로 그려진다.
   - 자료를 누르면 오른쪽에 **형상이 같은 자료(하중만 다름 등)** 와 판(R0 → R1).
   - **주황 선**(똑같은 BDF) → "업로드에서 막혔어야 할 예외, 정리 필요" — 데이터 품질 점검 도구로도 쓰인다.
3. **기준 바꾸기** — 구역 · 프로젝트로 바꾸면 같은 자료가 다른 관점으로 다시 모인다.
4. **확대** — 휠로 12배까지: 2배부터 자료 번호, 4.5배부터 제목.

연결의 뜻: 함께 등록(자료 하나에 호선 둘 이상) · 형상만 같음(형상 서명이 같고 물성·재료·하중 일부가 다름) ·
똑같은 BDF(네 서명 모두 같음). 판은 자료 안 파일 순서라 선으로 그리지 않는다.

## 갖춤 현황 · 선례 찾기 시연 순서(제안)

1. **지금** — 실제 LogBook `/coverage`: 자료 18건이라 칸이 듬성듬성하다. "확정한 자료가 곧 지도다."
2. **쌓이면** — 시안 파일의 갖춤 현황으로 전환(호선 20척 × 구역 12).
   - 오른쪽 **먼저 볼 칸**: 검증 실패 → 문서 없음 순. 하나를 누르면 그 칸 자료가 열린다.
   - 범례 「문서 없음」을 누르면 그 칸만 남는다 → "보고서를 안 쓴 해석이 이만큼."
   - 해석 종류 「권상」 → 권상을 하지 않는 구역은 빗금으로 빠진다. 「빠진 칸 표시」(2단계 미리보기) → 선종별 필수인데 빈 칸.
3. **선례 찾기** — 시안의 예시 단추 셋.
   - 「LNGC 새 호선 정반」: 같은 설계를 다시 쓴 자료가 한 줄(같은 설계 N개 자료)로 맨 위, 다른 점은 주황.
   - 「해상풍력 마스트」: 형상은 달라도 크기·단면이 닮은 선례, 검증 실패 선례에는 경고.
   - 「닮은 선례가 없는 경우」: 억지로 채우지 않고 '충분히 비슷한 선례가 없습니다'.
   - 실제 화면에서는 아무 BDF 나 끌어다 놓으면 같은 계산을 실제 자료로 한다(저장하지 않음).
