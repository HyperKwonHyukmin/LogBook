# LogBook 설명회 시연 자료

## 통합 데모 (설명회용)

**`LogBook-설명회-통합데모.html`을 Chrome에서 열면 됩니다.** 다른 파일이나 서버, 인터넷 연결 없이 실행됩니다.

- 첫 화면은 **관계 지도**입니다. 왼쪽 메뉴에서 **빈칸 지도 → 비슷한 선례**로 전환하며 설명할 수 있습니다.
- 관계 지도의 확대·호버·자료 상세, 빈칸 지도의 셀 선택, 비슷한 선례의 기준 모델 선택 등 기존 상호작용을 유지했습니다. 모델 점검 메뉴도 포함합니다.
- 각 화면은 독립된 예시 데이터입니다(관계 지도 64건 / 인사이트 자료 158건). 실제 운영 데이터가 아닙니다.
- `#graph`, `#coverage`, `#similar`, `#checks` 주소 조각으로 특정 화면부터 열 수도 있습니다.
- 아래 원본 HTML 두 개는 그대로 보관했습니다. 발표할 때는 통합 HTML 한 개만 복사하면 됩니다.

## 관계 지도 원본 데모

| 파일 | 내용 |
|---|---|
| `빈칸지도·비슷한선례-시안-예시데이터.html` | 갖춤 현황(26) · 선례 찾기(27) · 모델 점검(28, 미구현) 시안(구현 전 이름 빈칸 지도·비슷한 선례 시절에 만든 파일이라 파일 이름은 그대로). **예시 데이터 158건**(호선 20척 + 프로젝트 2 + 공용, 구역 12, 해석 종류 6, 표준 설계 재사용·검증 실패·튀는 모델 포함)으로 자료가 쌓였을 때의 모습. 더블클릭으로 열린다(글꼴만 인터넷에서 받고, 없으면 기본 글꼴). |
| `관계지도-시안6-예시데이터.html` | 관계 지도 시안 6. **예시 데이터 64건**(호선 7척, 자매선 모델 재사용, 강제 업로드 1쌍)으로 자료가 쌓였을 때의 모습을 보여 준다. 더블클릭으로 바로 열린다(d3 를 파일 안에 넣어 인터넷이 필요 없다). |

실제 화면은 LogBook `/graph`(25)이다. 시안과 그리는 방식·움직임이 같고 데이터만 실제 자료다.
예시 데이터는 실제 DB 구조(entries · entry_hulls · entry_tags · 내용 서명 · model_revisions)를 흉내 냈다.

## 발표 순서(제안)

1. **지금** — 실제 LogBook `/graph`: 자료 18건이 호선별로 모인 모습. "자료를 확정하는 것만으로 지도가 생긴다."
2. **쌓이면** — 이 시안 파일로 전환: 같은 화면에 자료 64건.
   - 호선 사이 **굵은 곡선**에 마우스 → "3496 ↔ 3542 · 관계 9건 · 함께 등록 4 · 형상이 같은 BDF 4쌍 …" 설명이 뜬다.
   - 호선 점에 마우스 → 주변이 가라앉고 연결이 바깥으로 그려진다.
   - 자료를 누르면 오른쪽에 **형상이 같은 자료(하중만 다름 등)** 와 판(R0 → R1).
   - **주황 선**(똑같은 BDF) → "업로드에서 막혔어야 할 예외, 정리 필요" — 데이터 품질 점검 도구로도 쓰인다.
3. **기준 바꾸기** — 구역 · 프로젝트로 바꾸면 같은 자료가 다른 관점으로 다시 모인다.
4. **확대** — 휠로 12배까지: 2배부터 자료 번호, 4.5배부터 제목.

연결의 뜻: 함께 등록(자료 하나에 호선 둘 이상) · 형상만 같음(형상 서명이 같고 물성·재료·하중 일부가 다름) ·
똑같은 BDF(네 서명 모두 같음). 판은 자료 안 파일 순서라 선으로 그리지 않는다.

## 갖춤 현황 · 선례 찾기 시연 순서(제안)

1. **지금** — 실제 LogBook `/coverage`: 자료 18건이라 칸이 듬성듬성하다. "확정한 자료가 곧 지도다."
2. **쌓이면** — 시안 파일의 갖춤 현황으로 전환(호선 20척 × 구역 12).
   - 오른쪽 **먼저 볼 칸**: 검증 실패 → 문서 없음 순. 하나를 누르면 그 칸 자료가 열린다.
   - 범례 「문서 없음」을 누르면 그 칸만 남는다 → "보고서를 안 쓴 해석이 이만큼."
   - 해석 종류 「권상」 → 권상을 하지 않는 구역은 빗금으로 빠진다. 「빠진 칸 표시」(2단계 미리보기) → 선종별 필수인데 빈 칸.
3. **선례 찾기** — 시안의 예시 단추 셋.
   - 「LNGC 새 호선 정반」: 같은 설계를 다시 쓴 자료가 한 줄(같은 설계 N개 자료)로 맨 위, 다른 점은 주황.
   - 「해상풍력 마스트」: 형상은 달라도 크기·단면이 닮은 선례, 검증 실패 선례에는 경고.
   - 「닮은 선례가 없는 경우」: 억지로 채우지 않고 '충분히 비슷한 선례가 없습니다'.
   - 실제 화면에서는 아무 BDF 나 끌어다 놓으면 같은 계산을 실제 자료로 한다(저장하지 않음).
