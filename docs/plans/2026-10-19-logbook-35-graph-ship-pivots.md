# 35 — 관계 지도 선종·선형 기준

사용자 요청(2026-10-19): "관계지도에서 선종별, 용량별로도 관계를 구축" → 검토안대로 진행.
30(PLM 선박 정보)으로 호선에 선형·선종이 쌓였으니, 관계 지도의 **모으는 기준**에 둘을 더한다: 호선 | 구역 | **선종** | **선형**.

## 결정

| 항목 | 결정 |
|---|---|
| 선종 | `hulls.ship_kind`(PLM 분해 값 'LNG'). 없으면 선종 칸 글자를 `plm_ship.parse_ship_type` 로 풀어서('300K-VLCC' → VLCC) |
| 선형 | `hulls.ship_type` 그대로('174K LNG') — 자매선·동형선 묶음. 사람이 고친 값도 따른다 |
| 용량만으로 묶기 | **하지 않는다** — 단위가 선종마다 다르다(LNG m³ · VLCC/B·C DWT · CNTR TEU). '용량별'은 선형으로 본다 |
| 호선이 여러 척 | 구역처럼 여러 기준에 함께 속한다(겹치는 값은 하나로) — '함께 등록' 곡선이 생긴다 |
| 값 없음 | 공용 자료·PLM 미조회 호선 → '선종 없음'·'선형 없음' 점 |

## 구조

- `backend/app/graph.py` — 응답에 `hull_kinds: {호선: 선종}` 를 더한다(`hulls: {호선: 선형}` 은 그대로). 저장 없음.
- `frontend/src/lib/graphModel.js` — `GROUP`·`PIVOTS`·`GROUP_KEYS` 에 `kind`·`type`, `valuesOf` 가 자료의 호선들에서 값을 모은다.
  기준 사이 곡선·고리·상세 칸·설명 문장은 기준 키만 보고 동작해 그대로 따라온다. `hull_kinds` 가 없는 응답도 '없음'으로.
- `GraphPage.jsx` — 모으는 기준 단추 4개(왼쪽 칸 224px 안 — 단추 약 44px × 4).
