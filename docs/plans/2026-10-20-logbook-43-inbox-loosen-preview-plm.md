# 43 — 정리 대기: 빈 칸 확정 허용 · 3D 미리보기 · PLM 자동 조회

작성 2026-10-20 · 상태: **구현 완료(개발 PC, 2026-10-20) — 145 화면·PLM 확인 남음** · 관련: 20(필수 분류)·30(PLM 선박 정보)·40(구역·대상)·42

## 왜(2026-10-20 사용자 요청)
1. 정리 대기에서 호선·구역·대상을 고르지 않아도 확정되게 — 나중에 고치는 편이 편할 수 있다.
2. 정리 대기에서도 모델을 3D 로 보고 분류를 고르고 싶다.
3. 업로드하면 호선을 PLM 에서 바로 찾아 호선 정보에 저장되게 — 지금까지는 '확정' 때만 자동 조회했다(30).

## 결정
- **빈 칸 확정 허용 + '보완 필요'.** 서버 `confirm` 의 `409 required_fields` 를 없앴다. 빈 칸은 확정 뒤
  `needs_fix`(자료 화면·관리 '자료 정비'·CLI `naming-cleanup`)로 남는다(20 의 기존 표시를 그대로 쓴다).
  막는 것은 제목뿐(제목은 업로드 때 초안이 채워진다). 정리 대기 '확인할 것'은 빈 호선·구역·대상을
  "확정은 되지만 '보완 필요'로 남습니다" 권장으로 보인다.
  - 대가: 빈 칸 자료는 관계 지도·갖춤 현황에서 묶이지 않는다. 발표자료 7쪽 '자료 올리기 시, 유의 사항'처럼 자세히 넣기를 계속 권한다.
- **3D 보기.** 정리 대기 카드의 BDF 줄에 변환이 끝나면(`3D 준비됨`) [3D 보기] — 카드 안에 자료 화면과 같은
  `ModelPreview`(요약·해석 검증·뷰어·전체 화면)를 펼친다. 한 번에 하나. 서버는 바꾸지 않았다(초안 파일도 올린 사람·관리자는 이미 볼 수 있다).
- **PLM 자동 조회를 정리 대기 단계로.** `plm_ship.register_hulls(db, 호선들)` = 호선 행 만들기 + 일괄 조회 작업(`plm_fill`, PLM 설정 시만).
  부르는 곳: 업로드 처리(`ingest/process.py`, 제안 호선) · 보고서 본문에서 찾은 호선(`extract/job.py`) · 자료 수정의 호선 변경
  (`update_entry` — 이제 초안도). 정리 대기 카드는 저장된 PLM 정보(`hulls[].plm`)를 호선 칸 아래에 자동으로 보인다(`HullPlmSummary`).
  - 호선 목록(`list_hulls`)은 확정 자료로만 세므로 초안에만 있는 호선은 목록에 끼지 않는다. 호선 행만 남는다(무해).
