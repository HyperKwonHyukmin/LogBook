# 74 — 팀 공간(팀 전용 자료)

작성 2026-11-25, 상태: **1~3단계 구현(커밋 전), 145 반영 남음**, 관련: 15(등급과 공개 단계), 54(일괄 분류), 60(WB 실행자 열람), 68(초안 담당자), 69(업무별 모음), 71(대상 묶음), 72(새 자료)

## 목적
선장설계부 배관해석 담당이 CAESAR II 해석 파일과 보고서를 **그 사람들끼리만** 보고 관리하는 공간으로 LogBook 을 쓰려 한다.
메뉴를 늘리지 않고, 공개 범위에 '팀' 단계를 더해 그 팀원과 관리자만 보게 한다. 팀 자료는 업무별 모음 목록 맨 위의 팀 줄에서 모아 본다.

처음에 나온 안('업무별 모음' 메뉴를 '워크스페이스'로 바꾸기)은 쓰지 않는다. 업무별 모음은 대상 기준으로 **모두에게 여는** 화면이고,
팀 공간은 사람 기준으로 **정한 사람에게만 여는** 공간이라 성격이 반대다. 메뉴 이름을 바꾸면 팀이 없는 대다수 사용자에게 빈 메뉴가 된다.

## 결정(2026-11-25 사용자와 질의응답)

### 권한
1. 공개 범위(`Entry.access`)에 **`team`** 을 더한다. 팀 자료는 그 팀원과 LV3(WorkBench 관리자 포함)만 본다.
   다른 사람에게는 검색, 호선, 관계 지도, 비슷한 모델 찾기, 업무별 모음 건수, 새 자료 숫자 어디에도 나오지 않고 주소로 와도 404(지금 '존재 자체를 숨긴다' 규칙).
2. **팀 자료에서는 팀원 누구나 올린 사람과 같다**: 고치기, 파일 추가, 휴지통과 복원, 초안 확정, 개별 허락, 공개 범위 바꾸기(일반이나 공유로 전체 공개 포함). 영구 삭제만 LV3.
3. 팀 초안(확정 전)도 팀원 모두가 보고 정리하고 확정한다.
4. 팀 소속과 등급(LV1~LV3)은 따로다. 배관팀 사람이 LV1 이면 공유 자료, 팀 자료, 자기 자료만 본다. 구조 쪽 '일반' 자료까지 볼 사람만 관리자가 LV2 로 올린다.
5. 팀에서 빠진 사람은 자기가 올린 팀 자료만 계속 본다(올린 사람 규칙). 개별 허락(`entry_grants`)은 지금처럼 공개 단계와 상관없이 작동한다.
6. 팀 밖 사람이 올린 자료를 팀 자료로 넣는 일은 **관리자만** 한다(팀 자료가 되면 팀원 누구나 고치고 지울 수 있게 되므로).

### 팀 구조와 관리
7. 팀 표와 팀원 표를 둬서 팀을 여럿 만들 수 있게 한다. **한 사람은 한 팀에만** 속한다. 관리자는 팀에 넣지 않아도 모두 본다. 첫 팀 = 배관해석.
8. 팀원 명단은 **관리자만** 고친다. 관리 › 사용자 화면에 위쪽 탭 '팀': 팀 만들기(이름, 한 줄 설명), 사번이나 이름으로 찾아 팀원 넣고 빼기, 팀 지우기는 팀 자료 0건일 때만. 바뀐 내용은 활동 로그에 남긴다.

### 올리기와 분류
9. 팀원이 올리는 자료의 공개 범위 기본값은 '팀'(CAESAR 파일이 없어도). 확정 전에 바꿀 수 있다. 팀원이 아닌 사람은 지금처럼 '일반'.
10. **CAESAR 파일이 든 자료는 누가 올리든 대상이 자동으로 '배관'**(사용자: "시저는 모두 배관 소속"). 공개 범위는 올린 사람에 따른다.
    관리자나 구조시스템 소속이 CAESAR 자료를 올릴 수도 있어서, CAESAR 라고 팀 자료로 자동 배정하지는 않는다(사용자 결정).
    판정 확장자 = 입력 파일 `.c2`(신형), `._A`(구형). 결과와 보조 파일은 판정에 쓰지 않는다. 첫 실제 업로드 때 확장자를 다시 확인한다.
    대상 목록에 '배관' 을 더한다. 구역은 비워도 확정된다(지금 확정 조건은 구역과 대상을 요구하지 않음, 확인함).
11. CAESAR 파일은 '기타' 종류로 보관만 한다. 미리보기와 입력 요약은 없다. 보고서(PDF, Word, Excel)는 지금처럼 본문 검색이 된다.
12. 파일 저장 위치는 그대로 `999_LogBook\10_Vault`(사용자 결정). 공유 폴더 권한은 소유자와 그룹 `AA_300_CF44` 가 모든 권한(2026-11-25 `icacls` 확인)이라,
    그 그룹 사람은 공유 폴더에서 팀 파일을 직접 볼 수 있다. **이 점을 배관팀에 미리 알린다.** 숨김은 LogBook 화면까지다.

### 화면
13. 메뉴는 늘리지 않는다. **업무별 모음 목록 맨 위**에 '팀 전용' 표시가 붙은 팀 줄, 팀원과 관리자에게만 보인다(관리자는 모든 팀 줄).
14. 팀 공간 화면(1단계): 팀 자료 목록(최근순, 검색 결과와 같은 카드)과 공간 안 찾기, 확정 전 팀 초안 건수와 '올리기와 확정' 링크, 팀원 명단.
    대상 화면처럼 꾸민 안내(먼저 볼 예제, 실적 표)는 자료가 쌓인 뒤. 검색 화면에 '팀 자료만' 거르기는 만들지 않는다(팀 공간 안 찾기와 겹침).
15. 팀원과 관리자의 업무별 모음에는 팀 줄과 '배관' 대상 줄이 함께 보인다. 대상 줄은 실적과 예제, 팀 공간은 팀 자료 전체 관리로 역할을 나눈다.
    다른 사람에게는 볼 수 있는 자료가 0건이라 '배관' 대상 줄도 숨는다(0건 대상은 숨김, 69 결정 8).
16. 이미 올라온 배관 자료는 관리자가 자료 상세나 일괄 분류에서 '팀' 으로 바꾼다. 일괄 분류(54)에 공개 범위 칸을 더한다. 옮기기 전용 도구는 만들지 않는다.

## 설계

### 데이터
- 새 표 `teams`(id, name 고유, description, created_at), `team_members`(team_id, employee_id **고유**(한 사람 한 팀), added_by, added_at).
- `entries.team_id`(NULL 가능, FK). `access == "team"` 이면 반드시 값이 있다. 공개 범위를 다른 값으로 바꾸면 `team_id` 를 비운다.
- 재구축 보존: `entry.json` 에 `team`(팀 이름), `registry.json` 에 팀과 팀원 명단. 재구축 때 팀이 없으면 이름으로 만들고 자료를 다시 묶는다.
- 팀 지우기는 `team_id` 를 가진 자료(휴지통 포함)가 0건일 때만. 자료별 기록 표를 새로 만들지는 않는다.

### 권한(`access.py`)
- `ACCESS_LABELS` 에 `team: "팀"`. `access_of` 가 `team` 을 알아보게.
- `visible_entries_filter`: 지금 LV2 조건이 `access != "blocked"` 하나뿐이라 **그대로 두면 팀 자료가 모든 LV2 에게 보인다.** `access.in_(("shared", "normal") + 옛 값)` 식으로 바꾸고,
  팀 조건 `and_(E.access == "team", E.team_id == 사용자 팀)` 을 더한다. `can_view_entry` 도 같은 규칙(`test_access_15` 가 둘을 비교).
- 새 `is_team_member(user, entry)`. `can_edit_entry`, `can_own_entry`, `can_manage_access`, `_check_confirmer`(서비스)에 '팀 자료의 팀원' 을 더한다.
- 공개 범위를 `team` 으로 바꾸는 요청: 팀원은 자기 팀으로만, 관리자는 아무 팀으로. 팀원이 아닌 올린 사람은 못 한다(결정 6).
- 사용자 팀 조회는 요청마다 한 번(로그인 사용자 객체에 캐시).

### 새는 길 점검(구현 때 하나씩 시험으로 막는다)
`visible_entries_filter`, `can_view_entry`, `ensure_visible` 를 쓰는 곳이 31개 파일이다. 필터를 거치지 않거나 캐시를 쓰는 길을 따로 본다.
- 보고서 본문 색인 검색(`report_index`), 관계 지도 특징 캐시(`report_index.features`, 자식 프로세스 계산), 비슷한 모델 찾기(`similar.py`)
- 업무별 모음 건수와 대상 화면(`targets.py`), 대상 묶음 건수(71), 호선 화면 건수, 선박 지도(73)
- 새 자료 숫자(`news.condition`), 최근 비교와 즐겨찾기, 프로필 카드(67) 분포, 관리 › 자료 현황(LV3 라 영향 없음 확인만)
- 파일 내려받기와 3D(lbm), WorkBench 가져오기 목록

### 화면
- 공개 범위 고르기: 팀원과 관리자에게만 '팀' 이 보인다(관리자는 팀 이름까지 고름). 올리기 창과 초안 상세의 기본값은 결정 9.
- 업무별 모음 `TargetsPage` 맨 위 팀 줄, 팀 공간 `/team/<id>`(탭 제목 `lib/pageTitle.js`), 관리 › 사용자 '팀' 탭.
- 자료 상세와 검색 카드에 '팀 전용' 표시(공개 범위 칩 자리).
- CAESAR 대상 자동: 올리기 정리(`ingest`)에서 초안에 `.c2`, `._A` 가 있으면 대상 기본값 '배관'(목록에 '배관' 이 없으면 비워 둠). 확장자 상수는 `ingest/rules.py` 한 곳.

## 단계
1. **서버 권한과 데이터**: 표, 열, `access` 규칙, 팀원 쓰기 권한, 재구축 보존, 새는 길 시험(`tests/test_teams_74.py`).

3. **팀 공간 화면**: 업무별 모음 팀 줄, `/team/<id>`, '팀 전용' 표시.
