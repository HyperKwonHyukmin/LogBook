# 54 — 여러 자료 분류 한꺼번에 바꾸기 (검색 결과에서 골라)

2026-11-05 · 상태: 구현, 145 확인 남음 · 선행 08(통제 어휘), 13(권한), 24(문서 분류 일괄), 43, 46(담당자)

## 목적
이미 올린 자료의 구역·대상·담당자가 제각각이거나 빠져 있을 때, 기존 분류를 보면서 여러 자료를 골라 한 번에 고친다.
지금까지는 자료 상세에서 한 건씩만 고칠 수 있었다(문서 분류만 24 에서 일괄).

## 구현
- **고르기(검색 화면):** 문서 보기에서 [여러 자료 고르기] → 행 왼쪽에 고르기 칸, 위쪽 띠에 "고른 자료 N건 · [보이는 자료 모두 고르기] · [분류 바꾸기] · [고른 것 비우기] · [고르기 끝내기]".
  고른 것은 검색을 바꿔도 남는다(구역 A 로 거르고 고른 뒤 B 로 거르고 더 고를 수 있다). 묶어 보기에서도 된다. 읽기 전용(로그인 정보 없음)은 단추가 없다.
- **분류 목록에서 들어가기:** 관리 › 분류 목록의 '사용' 수를 누르면 그 값으로 거른 검색이 열린다.
- **바꾸기 창(`BulkClassifyDialog`):** 구역 더하기·빼기, 대상(그대로 / 이 값으로 / 비우기), 호선 없음(공용) 표시·풀기, 담당자 더하기·빼기.
  고른 칸만 보낸다(`bulkBody`). [미리보기](서버 dry_run) → "바뀜 n · 이미 그 값 n · 건너뜀 n(이유)" → [n건 바꾸기] → 결과 한 줄, 검색 다시 부르기.
- **서버 `POST /api/entries/bulk-classify`(`entries/bulk.py`):** 최대 500건. 더할 값은 한 번만 정리(동의어 → 용어, 목록 밖 새 구역·대상은 관리자만 — 아니면 전체 422).
  자료마다 볼 수 있는지·고칠 수 있는지(올린 사람·관리자, 13) 확인 → 바뀌는 칸만 모아 `update_entry` 를 부른다.
  그래서 한 건씩 고친 것과 같은 감사 `ENTRY_UPDATE`·version +1·`entry.json`·사람이 고치지 않은 초안 제목 따라가기가 그대로다.
  안 되는 자료는 건너뛰고 이유(찾을 수 없음·고칠 권한 없음·다른 사람이 막 고침 등)를 돌려준다.
- ⚠ **공용 표시는 호선이 있는 자료에 걸지 않는다** — `update_entry` 는 '공용' 을 고르면 호선을 비우므로, 일괄로 걸면 호선이 지워진다. 그런 자료는 '호선이 있어 공용으로 바꾸지 않음' 으로 건너뛴다.
- 담당자 빼기는 명부에 있는 사람(id)만. WorkBench 에서 고른 아직 명부에 없는 사람은 어떤 자료의 담당자일 수도 없어 뺄 것이 없다.

## 하지 않는 것
- 제목·설명·결론·주의점 — 자료마다 다른 값이다.
- 호선 — 잘못 바꾸면 피해가 크고 자료마다 다르다.
- 자유 태그 — 화면에 입력 칸이 없다.
- 되돌리기 단추 — 자료마다 감사 기록(바뀌기 전 값)이 남으므로 필요하면 그걸 보고 다시 일괄로 바꾼다. 자주 필요하면 그때 만든다.
