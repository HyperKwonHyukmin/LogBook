# 24 — 문서 분류 여러 개 한꺼번에 바꾸기

> 같은 날 Codex 의 `2026-10-12-logbook-24-draft-attachments.md`(첨부 대기)와 번호가 겹친다. 서로 무관한 작업이다.

## 목적

이미 올라와 있는 문서(보고서·발표자료 등)를 문서 화면(`/reports`)에서 체크박스로 여러 개 골라 문서 분류를 한 번에 바꾼다.
예: 확장자 추정('자동')으로만 발표자료였던 .pptx 들을 '발표자료'로 확정, 미분류 PDF 여러 개를 '해석 보고서'로.

## 서버

- `POST /api/reports/meta/bulk` 본문 `{file_ids: [...], document_type: "발표자료"}` (`""` = 미분류, 단건과 같다)
  → `{updated: [{file_id, before, document_type, version}], skipped: [{file_id, reason}]}` (부분 성공, 200).
- 계산은 `report_catalog.save_document_types` 한 곳. **건마다 단건 저장과 같은 길**(`report_file` → `save`)을 거쳐
  권한(올린 사람·LV3)·감사 로그(`REPORT_META` 건별, target = 자료)·entry.json `reports` 반영이 단건과 똑같다.
  - `save` 에 `version=None`(판 확인 생략 — 목록에서 고른 값이라 판을 모른다), `model_ids=None`(모델 연결 그대로)을 더했고,
    바뀐 것이 있었는지 bool 을 돌려준다. 단건 PUT 은 동작이 같다.
- 422(아무것도 바꾸지 않음): 목록에 없는 분류 `invalid_document_type` · 빈 목록 · 중복 제거 뒤 200건 초과 `too_many_reports`.
- 건별 건너뜀 사유: `report_not_found`(없음·휴지통·초안·볼 수 없음 — 존재를 숨긴다), `not_uploader`/`read_only_role`(권한),
  `unchanged`(이미 같은 값 — 감사 로그·판 올림 없음).
- 저장값 없이 '자동'으로 보이던 .ppt/.pptx 를 '발표자료'로 보내면 같은 값이어도 저장해 확정한다(단건 규칙 그대로) → '자동' 표시가 사라진다.
- 목록 응답 행에 `can_edit`(그 쪽 문서만 계산)을 더했다 — 체크박스 활성 판단용.

## 화면 (`ReportsPage.jsx`, 계산은 `lib/reportBulk.js`)

- 행마다 체크박스(`<파일명> 선택`), 머리행 '현재 목록 전체 선택'(일부 선택이면 indeterminate). 고칠 수 없는 행은 비활성 + title 사유.
- 1건 이상 고르면 목록 위 작업 바: `N건 선택 · 분류 [목록] [적용] [해석 보고서(으)로] [발표자료(으)로] [선택 해제]`.
- 적용 전 확인 대화상자: 지금 분류별 건수 → 새 분류, 이미 같은 값이라 건너뛸 건수. 적용 뒤 결과 토스트(변경 N건 · 건너뜀 M건(사유별)),
  목록 다시 불러오기, 선택 해제.
- 선택은 지금 보이는 쪽 안에서만 유지 — 새 목록이 오면(거르기·검색·쪽 이동·저장 후 갱신) 그 목록의 고칠 수 있는 행만 남긴다.

## 한계

- 판 확인을 하지 않으므로 같은 문서를 다른 사람이 동시에 고치면 마지막 저장이 이긴다(감사 로그에는 둘 다 남는다).
- 선택은 한 쪽(최대 50건) 안에서만 — 여러 쪽을 넘나드는 선택은 없다. 서버 상한은 200건.
- 바꾸는 것은 문서 분류뿐이다. 모델 연결·자료 값(프로젝트·소속)은 단건 화면·자료 상세에서 바꾼다.
- 건마다 따로 커밋하고 entry.json 을 쓴다(같은 자료의 문서가 여러 개면 entry.json 을 그 수만큼 다시 쓴다).
