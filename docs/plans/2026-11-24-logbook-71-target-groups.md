# 71 대상 묶음(상위 분류)

상태: 구현(2026-11-24). 사용자 요청: "기타 적용된 모델을 그래도 상위 개념으로 할당하여 분류 가능하도록".

## 왜
145 운영 자료 점검(2026-11-24)에서 대상 '기타' 12건, 구역 '기타' 76건이 나왔다. 구역은 배 안의 위치라 위치가 없는 자료
(모듈 유닛 권상, 정반과 족장, 자동화 프로그램)는 '기타'가 맞다. 대신 대상에 상위 개념이 없어서, 구체적인 대상이 안 맞는 자료는
'기타'로 갈 수밖에 없었다. 대상 31개가 한 줄로 늘어서 업무별 모음과 필터에서 찾기도 어려워지고 있다.

## 무엇
- 대상 용어 위에 한 단계 '묶음'을 둔다. 묶음도 보통의 대상 용어다('배관'). 하위 용어(Manifold, Pipe, Support)에 소속 묶음을 하나 붙인다.
- 자료는 구체적인 용어나 묶음 자체로 분류한다. 구체적인 대상이 안 맞으면 '기타' 대신 묶음으로.
- 검색 필터 '배관' = 배관 자료와 하위 용어 자료 모두. 필터와 분류 화면의 건수도 하위를 합쳐 센다. 낱말 검색 '배관'도 하위 자료를 찾는다.
- 업무별 모음: 묶음 행 아래 하위 업무를 들여 쓴다. 묶음 화면에는 하위 자료가 모두 모이고, 하위 업무로 가는 링크가 있다.
- 관리 › 분류 목록 › 대상: '묶음' 고르기 칸. 감사 기록(VOCAB_TERM_UPDATE 의 parent)과 registry.json(vocab 의 parent)에 남아 재구축 때 되살린다.

## 규칙
- 한 단계만: 하위가 있는 용어는 다른 묶음에 들어가지 못하고, 묶음에 든 용어는 묶음이 되지 못한다. '기타'는 묶음도 하위도 아니다.
- 대상에만(구역은 위치라 묶지 않는다).
- 검색 결과를 대상으로 '묶어 보기'(group=target)는 자료를 자기 값 칸에만 둔다(배관 칸 = 배관으로 직접 분류한 자료). 하위 자료까지 넣으면 같은 자료가 두 칸에 겹쳐 나온다. 그래서 필터 건수(하위 포함)와 묶음 칸 건수가 다를 수 있다(Codex 검토 2026-11-24, 의도).
- 검색어 전체가 공백 든 대상 용어('선체 구조')면 낱말로 나누지 않고 한 덩어리로 찾는다(나누면 하위 자료가 빠진다).
- 묶음 용어를 지우면 하위 용어의 연결도 끊는다. 사용 중지한 묶음은 연결과 검색 합산이 그대로다.
- 표에는 `tags.parent_id`(INT NULL) 하나만 더한다(기존 DB 는 ensure_columns). 묶음 용어가 지워지거나 동의어로 합쳐져 맞지 않는 연결은 읽을 때 무시한다(쓰기마다 정리하지 않는다).

## 첫 묶음(제안, 운영 자료 제목 기준 — 관리 화면에서 바꿀 수 있다)
| 묶음 | 하위 대상 |
|---|---|
| 선체 구조 | 전선 모델, 블록, 하중분산판, PumpTower, 서비스타워 |
| 의장품 | 계류 의장품, 래싱 브리지, 해치 커버, 레이더 마스트, Foremast, 라이팅 포스트, 장비 받침, 크레인 받침, LifeBoat, Ladder, Handrail, Catwalk, Platform, SidePassage |
| 배관 | Manifold, Pipe, Support |
| 추진 및 조타 | Shaft, Rudder, PSD |
| 생산 및 권상 | Unit, Truss, 정반, Skid, 권상 러그 |
| 해석 기법 | (하위 없음) 자동화 프로그램, 해석 방법 자료 |

묶음 이름에 쉼표와 가운뎃점을 쓰지 않는다(필터 값 구분과 문구 규칙).

## 운영 적용 순서(배포 뒤, API 로)
1. 새 묶음 용어 추가(선체 구조, 배관, 추진 및 조타, 생산 및 권상, 해석 기법. 의장품은 이미 있다)
2. 하위 용어에 묶음 지정(PATCH /api/vocab/terms/{id} {parent})
3. 대상 '기타' 자료 옮기기(bulk-classify dry_run 뒤): E000267, E000157, E000153 → 선체 구조 / E000142, E000144 → 배관 / E000125 → Pipe /
   E000258 → 추진 및 조타 / E000101 → 생산 및 권상 / E000084, E000085, E000115 → 해석 기법
