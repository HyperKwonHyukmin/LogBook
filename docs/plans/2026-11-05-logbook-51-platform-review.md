## 검토했지만 고치지 않은 것(이유)

- `GET /api/hulls/{no}/plm` 이 LV1 도 저장: **의도된 설계**(PLM 사실값만, 사람이 고친 선종은 덮지 않음 — `test_plm_ship_30.py` 주석).
- 기존 자료에 합치는 확정(`merge_into`)이 초안의 분류를 옮기지 않음: 화면이 '파일이 추가됩니다'라고 안내하는 동작이라 대상 자료의 분류를 바꾸지 않는 것이 맞다.
- `/sso` 일회 코드에 state 없음(로그인 CSRF): 기전은 맞지만 로그인이 사번만이라(2026-10-20 결정) 직접 사번 입력이 더 쉬운 길. 본인 확인과 함께 `hitess-core` 에서 다룬다.
- 활동 로그에 배치 키·자료에서 뺀 파일 번호가 LV1 에게 보임: 드러나는 것은 작업자·시각·배치 키·숫자 id 뿐(내용·자료 번호·제목은 47 에서 이미 가림). 자료가 수천 건이 되면 `NOT IN` 목록을 서브쿼리로 바꾼다.
- 발췌 강조 위치가 `lower()` 로 글자 수가 바뀌는 문자(İ 등)에서 밀림: 실제 보고서에 거의 없음.
