# 26 — 갖춤 현황

메뉴 이름은 처음 '빈칸 지도'였다가 화면의 칸 상태 이름(갖춤·문서 없음·모델 없음)에 맞춰 '갖춤 현황'으로 정했다(2026-10-16).

설계 초안: `docs/specs/2026-10-16-logbook-model-insight-design.md` 26절. 예시 데이터 시안: `docs/demo/빈칸지도·비슷한선례-시안-예시데이터.html`.

## 사용자 흐름

1. 내비 **갖춤 현황**(`/coverage`)을 연다. 행 = 호선(번호 순) → 프로젝트 → 공용 → 미지정, 열 = 구역(자료 많은 순 14개,
   나머지는 '기타', 구역 없는 자료가 있으면 '구역 없음'). 칸 안 숫자는 자료 수다.
2. 칸 상태는 색 + 모양으로 말한다.

   | 상태 | 판정 | 모양 |
   |---|---|---|
   | 갖춤 | 모델 + 문서(또는 다른 자료 문서가 이 모델을 연결), 모델이 모두 검증 실패는 아님 | 남색 채움 |
   | 문서 없음 | 모델만 | 옅은 남색 + 모서리 잘림 |
   | 모델 없음 | 문서만(다른 자료 모델과 연결된 문서뿐이면 갖춤으로 센다) | 흰 바탕 + 남색 점선 |
   | 검증 실패만 | 칸의 모델 자료가 모두 해석 검증(06) 실패 | 빨강 옅은 바탕 + 점 |
   | 비어 있음 | 자료 없음 | 회색 점선 |
   | 해당 없음 | 해석 종류로 걸렀을 때 그 구역 어디에도 그 해석 종류 자료가 없음 | 빗금(누를 수 없음) |

3. 칸에 올리거나 포커스하면 이유 한 줄, 누르면 오른쪽에 그 칸의 자료. 빈 칸이면 같은 선종 다른 호선의 같은 구역,
   같은 행의 다른 구역 자료를 참고로 보인다. 아무 칸도 고르지 않았으면 오른쪽은 **먼저 볼 칸**(검증 실패 → 문서 없음, 최근 순).
4. 범례를 누르면 그 상태 칸만 남는다. 해석 종류로 거르면 격자·범례·목록이 함께 다시 센다. 방향키로 칸 이동, Enter 로 연다.
5. 아래 **손볼 자료 목록** 탭 — 문서 없는 모델 · 모델 없는 문서 · 해석 검증 실패 · 분류 보완 필요(20) · 서명 없는 모델(12).
   칸을 고르면 [그 칸만 보기]로 목록을 좁힌다.

## 처리 방식

- 저장하지 않는다. `GET /api/coverage`(`app/coverage.py`)가 확정 자료마다 사실(행·구역·모델/문서 수·자료 사이 보고서↔모델
  연결·검증 요약·보완 필요·서명 없음·올린 사람)을 한 번에 싣고, 칸 계산은 프런트 `lib/coverage.js`(순수 함수·테스트)가 한다.
  해석 종류를 바꿔도 다시 부르지 않는다.
- 권한: 보는 사람이 볼 수 있는 확정 자료만(`visible_entries_filter`). 보고서↔모델 연결도 상대 자료가 보일 때만 센다.
- 구역·프로젝트는 분류 목록의 대표 값(`Vocab.root`) — 동의어가 다른 열로 갈라지지 않는다.
- 검증 요약: 하나라도 통과면 pass, 검증한 모델이 모두 fail 이면 fail(검증 안 한 모델이 있으면 none). error(실행 문제)는 실패로 세지 않는다.
- 상한: 최근 확정 3000건(`truncated`, 관계 지도와 같다).

## 나중 단계

- **선종별 필수 해석**(`coverage_expectations(ship_type, zone, analysis_type)`, 관리 화면에서 정함) — 있어야 하는데 빈 칸을 빨강으로.
  시안에는 미리보기로 들어 있다.
- 목록 탭 '점검 주의' — 28 모델 점검이 들어오면 더한다.
