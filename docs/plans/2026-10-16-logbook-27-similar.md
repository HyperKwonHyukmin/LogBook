# 27 — 선례 찾기

메뉴 이름은 처음 '비슷한 선례'였다가 화면의 쓰임(해석 전에 선례를 찾는다)을 동사로 말하는 '선례 찾기'로 정했다(2026-10-16).

설계 초안: `docs/specs/2026-10-16-logbook-model-insight-design.md` 28절(번호를 구현 순서에 맞춰 27 로 당겼다 — 모델 점검이 28).

## 사용자 흐름

1. 들어오는 길: 자료 화면·검색 미리보기의 BDF [선례 찾기](`/similar?file=<id>`), 또는 내비 **선례 찾기**에서
   - **LogBook 에서 고르기**(기준이 없으면 처음부터 열림): 검색(`/api/search?unit=file&kind=model`)으로 호선·제목·파일 이름·자료 번호를
     찾고, 검색어가 없으면 최근 올린 BDF, 범위 전체 | 즐겨찾기. 썸네일·호선·자료 번호, ↑/↓·Enter. 변환이 끝난 확정 자료만 고를 수 있다
     (`components/similar/ModelPicker.jsx`). 고르면 주소가 `?file=<id>` 로 바뀐다.
   - **내 PC 에서 고르기** 또는 끌어다 놓기(32MB 까지, 저장하지 않는다).
2. 기준 칸: 썸네일·크기·요소·구성·단면 수. 구역·해석 종류를 고르면(기준 자료가 있으면 그 값이 기본) 분류 점수에 들어간다.
3. 결과(최대 10줄): **같은 형상 서명은 한 줄**('같은 설계 N개 자료' + 호선 칩, 펼치면 자료 목록). 줄마다 검증 결과·문서 수·
   올린 사람·확정 월, **같은 점 / 다른 점**(다른 점은 주황), 닮은 정도는 말(거의 같음 / 많이 비슷 / 일부 비슷 / 참고만) + 작은 숫자.
   검증 실패 선례에는 '그대로 가져다 쓰기 전에 원인 확인' 경고. 정렬: 닮은 순 | 검증 통과·문서 있는 것 먼저.
4. 가장 닮은 것도 0.5 미만이면 '충분히 비슷한 선례가 없습니다' + 3개만 참고로 + 갖춤 현황로 가는 단추.
5. 오른쪽: 기준과 선례 썸네일, 크기·요소·구성·구역·해석 종류·SOL 표(다른 값 주황), 단면 합집합(같은 것·기준만·선례만),
   항목별 점수, [자료 열기] [나란히 비교](기준이 LogBook 자료일 때) [3D 로 보기]. ↑/↓ 로 선례 이동.

## 처리 방식

- 새로 저장하는 값이 없다. 특징은 `model_summaries` 의 counts·bbox·fingerprint·sol·sig_geometry 에서 읽는다(`app/similar.py`).
  - 크기: bbox 를 정렬한 L ≥ W ≥ H. 가장 긴 변이 500 을 넘으면 mm 로 보고 m 로 바꾼다.
  - 단면: fingerprint 의 단면 표기(`PBEAML L 100x100x10` → `L 100x100x10`, `PSHELL t12` → `t12`).
- 점수(항목별 0~1): 크기 exp(−로그 거리) 0.30 · 규모·촘촘함 0.20 · 구성(보·쉘·강체·질량 비율 코사인³) 0.20 ·
  단면 Jaccard 0.20 · 분류(같은 구역 0.6 + 같은 해석 종류 0.4) 0.10. 형상 서명이 같으면 0.9 + 0.1 × 나머지(맨 위).
- 같은 자료 안 여러 BDF(판)는 가장 닮은 하나만, 같은 형상 서명은 한 줄. 대표는 거의 같은 점수(−0.03) 중 검증 통과 → 문서 있음.
- API: `GET /api/similar?file_id=&zone=&analysis_type=`(볼 수 없거나 변환 안 된 기준은 404 `similar_base_not_found`),
  `POST /api/similar/bdf?name=&zone=&analysis_type=`(본문 = BDF 바이트, 요청 안에서 읽는다 — INCLUDE 는 따라가지 않는다.
  413 `bdf_too_large`, 422 `bdf_drm`·`bdf_no_elements`·`bdf_model_error`). 올린 BDF 도 형상 서명을 계산하므로 같은 설계를 찾는다.
- 권한: 비교 대상은 보는 사람이 볼 수 있는 확정 자료의 BDF 만. 후보 상한 5000.
- 프런트: 문장·정렬은 `lib/similar.js`(순수 함수·테스트), 화면 `pages/SimilarPage.jsx`(따로 묶어 늦게 불러옴).

## 배포

`git pull` + 프런트 빌드(의존성 변경 없음) + 서버 재시작. DB 변경 없음. 서명 없는 BDF 는 같은 설계 묶기에서만 빠진다.
