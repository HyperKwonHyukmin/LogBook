# 40 — 구역·대상 뜻 나누기(구역에 들어간 구조물 값을 대상으로)

작성 2026-10-19 · 상태: **계획(구현 전 — Core 다음)** · 관련: 08(통제 어휘)·18-b(WorkBench 보내기 제한)·20(필수 분류)·26·25·38(대상)

## 문제
- 정의상 **구역(zone)** = 배 안의 *위치*(선수부·선미부·화물창·기관실·거주구·상갑판·이중저), **대상(target, 38)** = *무엇을 해석했나*
  (전선 모델·블록·계류 의장품·크레인 받침·해치 커버…). 두 축이라 겹치지 않아야 한다.
- 그런데 대상 칸(38)보다 먼저 생긴 WorkBench 보내기 제한(18-b, `wb_targets.py`)이 **구역·자유 태그만** 본다
  (기본 규칙 truss = 구역 'Truss'). 그래서 `Unit`·`Truss` 처럼 사실은 *대상*인 값이 구역 목록에 들어갔다.
- 결과
  - BDF 필수 분류(20, `quality.REQUIRED`)가 구역을 요구해 위치 개념이 없는 모델(Unit·Truss·전선 모델)에도 구역을 억지로 넣는다.
  - '선수부의 계류 의장품' 같은 위치 × 대상 거르기가 안 된다. 제목이 `3496 · Unit · 권상 해석 · Unit` 처럼 같은 말을 되풀이할 수 있다.
  - 갖춤 현황(26)·관계 지도(25)의 구역 축에 위치와 구조물이 섞인다.

## 결정
**두 칸은 그대로 두고 뜻을 바로잡는다.** 하나로 합치지 않는다 — 갖춤 현황(호선 × 구역)·관계 지도 구역 기준·제목 형식이
구역 축에 기대고, 두 축으로 거르는 이점을 잃는다.

| 칸 | 뜻 | 예 | 여럿 |
|---|---|---|---|
| 구역 | 배 안의 위치 | 선수부·기관실·거주구 | 여럿 |
| 대상 | 해석한 구조물·모델 단위 | 전선 모델·블록·Unit·Truss·크레인 받침 | 하나 |

## 단계
1. **종류 옮기기**(`vocab.move_term(kind_from, value, kind_to)` + CLI `vocab-move zone Unit target`, `--apply` 없으면 보고만)
   - 용어와 동의어 묶음을 대상 목록으로(같은 이름이 대상에 이미 있으면 그 용어로 합침).
   - 그 구역을 단 자료: 대상이 비었으면 대상으로, **이미 다른 대상이 있으면 옮기지 않고 보고**(대상은 자료당 하나).
     구역에서는 뺀다. 감사 `ENTRY_UPDATE`(system actor) + `VOCAB_MOVE`, entry.json·registry 갱신(write_meta 작업).
   - 지금 합치기(`merge_value`)는 같은 종류 안에서만이라 새 함수가 필요하다.
2. **WorkBench 규칙에 대상 추가** — `wb_target_rules.targets`(JSON) 열(스키마 변경 → 테스트 `@pytest.mark.fresh_schema`),
   판정은 구역·대상·태그 중 하나라도(OR). 기본 규칙 truss = 대상 'Truss'(+ 태그 'Truss'), 관리자가 손대지 않은 옛 기본값은 한 번 올린다
   (`_OLD_SEEDS` 방식). 1단계가 옮긴 값은 규칙의 `zones` 에서 `targets` 로 함께 옮긴다. 관리 화면에 '대상' 입력, 선택 띠 문구 "대상 'Unit'".
3. **필수 분류** — BDF 자료는 `구역 또는 대상 중 하나`(누락 이름 `zone` → `zone_or_target`, 라벨 '구역 또는 대상').
   자료 정비(20)·갖춤 현황 '분류 보완' 목록이 같은 규칙을 쓴다.
4. **기본 목록·문서** — `vocab.DEFAULTS` 의 두 목록 설명 주석, 관리 '분류 목록' 탭에 한 줄 정의(구역 = 위치, 대상 = 구조물),
   README 분류 설명. 18-b 계획서에 '이제 대상으로 제한' 메모.
5. **화면 확인** — 갖춤 현황 구역 열에서 Unit·Truss 가 빠지는지, 관계 지도 구역 기준, 정리 대기 카드 필수 표시.

## 하지 않는 것
- 구역·대상 하나로 합치기, 대상을 여러 개 허용하기(38 결정 유지).
- 업로드 이름에서 구역·대상 추정(38 남은 일 그대로).
