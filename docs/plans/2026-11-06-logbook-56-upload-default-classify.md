# 56 — 업로드 기본 분류(폴더 이름과 비슷한 기존 자료의 값)

2026-11-06 사용자 요청: 정리 대기에서 폴더를 올리면, 이미 같은 대상을 올린 자료가 있을 때 그 자료의 구역·대상을 자동으로 골라 둔다.
예: `6_Rudder` 를 올리면 이미 있는 Rudder 자료의 구역·대상이 폴더 올리기 창에 미리 들어간다. 사람이 보고 고치거나 그대로 올린다.

처음 구현(같은 날 다른 세션, 미커밋)은 "본인이 마지막으로 확정한 자료"의 값을 넣었다. 사용자가 뜻을 다시 알려 주어 기준을 바꿨다.
직전 자료가 Hatch cover 였다면 6_Rudder 에 Hatch cover 의 분류가 들어가기 때문이다.

## 정한 것
- **기준 = 이름이 겹치는 기존 확정 자료.** `app/uploads/hint.py` `similar_preset()` 이 찾는다.
  - 올리는 폴더 이름(폴더가 없으면 파일 이름)을 낱말로 나눈다. 숫자·호선 번호·날짜·사번·판 표기(rev0·v2)·흔한 말(구조·해석·강도·평가·보고서·doc 등, `GENERIC`)은 뺀다.
  - 내가 볼 수 있는 확정 자료의 제목·원래 이름 + 구역·대상·자유 태그(동의어 포함) 낱말과 비교한다.
  - 겹치는 낱말이 가장 많은 자료를 고르고, 같으면 최근에 확정된 자료를 고른다.
- **가져오는 칸: 구역·대상만.** 담당자는 같은 대상이라도 이번에 맡은 사람이 다르므로 가져오지 않는다. 호선·결론·설명도 가져오지 않는다.
- **겹치는 자료가 없으면 비워 둔다.** 다른 자료로 채우지 않는다. 엉뚱한 값은 확인 없이 확정되기 쉬워 빈칸보다 나쁘다.
- 구역·대상이 비어 있는 자료는 줄 값이 없으니 고르지 않는다.

## 동작
- **초안마다 따로 찾는다**(`ingest/process.py`). 사람이 고른 공통 분류가 없으면, 초안마다 자기 폴더·파일 이름(`title_source`)으로 `similar_preset` 을 부른다.
  - `2021` 을 하위 폴더마다 나눠 올리면 `5_Rudder_3143` 은 Rudder 자료를, `Manifold_support` 는 Manifold 자료를 따른다. 맞는 자료가 없는 폴더는 빈칸이다(logbook-4a 세션 요청, 2026-11-06).
  - 찾은 자료 번호는 `batches.preset.hints = {초안 번호: 자료 번호}` 에 남는다. 정리 대기 카드는 그 초안의 `preset_from` 으로 "비슷한 기존 자료 E… 의 구역·대상을 기본값으로 넣었습니다. 다르면 고치세요." 를 보인다.
- `POST /api/uploads` 의 `preset`
  - 사람이 고른 값이 있으면 그 값을 모든 초안에 넣는다(먼저).
  - 비워 보냈으면 `{"skip_hint": true}` — 사람이 자동 채움을 지운 것이니 서버도 채우지 않는다.
  - 보내지 않았으면(파일 끌어 놓기·하위 폴더마다 나누기를 비운 채) 위의 초안마다 찾기를 한다.
- 폴더 올리기 창
  - '폴더 전체를 자료 1건': `POST /api/uploads/similar-preset {texts: [폴더 이름]}` 로 구역·대상 칸을 미리 채우고 "비슷한 기존 자료 E…(제목)의 구역·대상을 넣었습니다" 를 보인다. 사람이 먼저 고친 칸은 덮지 않는다. 늘 `preset` 을 보낸다.
  - '하위 폴더마다 자료 1건': 한 값이 모든 초안에 맞지 않으니 칸을 채우지 않는다. 비워 두면 `preset` 을 보내지 않아 서버가 초안마다 찾는다. 사람이 값을 고르면 그 값이 모든 초안에 들어간다.
- 기존 자료에 파일 추가(target)나 WorkBench 에서 온 묶음은 그대로 둔다(기본값을 넣지 않음).
